# Daily Time in Java

This Java program defines an interface DailyTime and implements it in the Time class. The program displays the total number of hours in a day.

## Features
Uses an interface DailyTime with two methods:

**getHours()**: Returns the number of hours in a day (24).

**displayHours()**: Prints the total number of hours in a day.

Implements the interface in the **Time** class.

## Usage
Compile the Java file:
javac Time.java

Create a main class to run the program:
javac Main.java

java Main

## Expected Output:
Total number of hours in a day equals: 24
